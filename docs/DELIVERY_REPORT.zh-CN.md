# v0.2 交付 / 验证报告

**工程状态：** 真实可运行的单机静态网页 RSS 原型，仍非生产成品。**验收时间：** 2026-10-21。

## 与 v0.1 相比的实际改动

- HTTP 客户端改为 aiohttp，自定义公开地址 Resolver，防 DNS 解析时与连接时结果变化；阻止 127.1 等短写地址。
- 保留重定向上限、响应大小、内容类型和超时约束；支持 JSON Feed 1.0/1.1 的 URL、标题、发布时间和摘要映射。
- 修复历史累计失败不断扩大退避时间的问题：改为 `consecutive_failures`，成功立即归零。旧 SQLite 数据库自动增加字段。
- 被同域名限速而延迟的源写入下一次调度时间，避免同域名条目反复占据队头。
- 抓取连接全局并发限制为 4 个；单实例调度原则保持不变。
- Recipe Bundle 升级到 v2，备份包含 Feed ID，可在空实例恢复原 RSS 路径；继续兼容 v1。支持恢复暂停状态。
- 增加多种非法地址回归检查、DNS 混合公共/私有地址、后退重试、JSON Feed 及备份恢复测试。
- 改善 XML 不合法字符处理；来源本身没有真实发布时间时，不伪造 `pubDate`。
- 管理 UI 新增搜索/状态筛选、来源最近内容和运行记录、暂停/恢复；展示已配置的 `OPENFEED_PUBLIC_URL`。
- Docker 加入只读根文件系统、临时目录和健康检查；CI 验证 Python 编译、测试、JS 语法。

## 测试边界

- 本地自动化：Python pytest、JS 语法、Python 编译。
- HTTP 实际源站：**尚无联网端到端核验**；公共网页调研只能说明部分内容的可见性，不能替代真实运行中的抓取与 Reader 订阅。
- 实际视觉浏览器：本执行环境无可用的 Playwright 浏览器二进制；未运行界面自动点击 E2E。已静态检查页面/JS 代码。
- 当前未接入：Browser JS 抓取、OpenPicker 浏览器扩展、html2rss 自动侦察引擎、完整 Feed43 匹配语义、PDF enclosure、搜索分页、职位生命周期、AI 自动修复。
