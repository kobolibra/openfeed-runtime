# 抓取质量保护规则

新增 `recipe.min_items`（0–300）与 `recipe.min_dated_pct`（0–100），默认均为 0（关闭）。

- `min_items`：成功提取的有效、去重后文章不足设定数量，整次刷新判为失败。适用于文章列表应保持一定最小规模的来源；不适合内容数量正常波动较大的栏目。
- `min_dated_pct`：成功提取的文章中，已解析发布日期所占比例低于阈值时，整次刷新失败。对于故意隐藏日期的页面保持 0。
- 校验位置：URL 和字段质量验证之后、`Store.finish` 持久化之前。沿用旧 Feed 保留与失败重试机制。
- 在 Studio 中编辑 Feed，可设置两项门槛。历史 Recipe 未包含这些字段也按 0 处理，无数据库迁移。
- 本地测试：`PYTHONPATH=. pytest -q`；新增测试覆盖输入范围、文章数量异常、日期覆盖率异常。

此功能只能检测设置的门槛是否被突破，不能替代真实网站的持续验收或百分之百保证无漏抓。
