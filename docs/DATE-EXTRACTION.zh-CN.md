# 从网页混合文本提取明确日期

默认 `date_format: auto` 仍要求字段本身可被严格解析，不猜测发布日期。

网页把分类、日期和标题放在同一段文字时，可显式设置：

```json
{
  "mode": "css",
  "item_selector": ".article-card",
  "fields": {"title": "h3", "link": "h3 a@href", "date": ".metadata"},
  "date_format": "embedded_calendar"
}
```

支持 CSS、XPath、Feed43 模式和 JSON。仅识别完整的 `2026-10-08`、`2026年10月8日`、`Oct 8, 2026`、`October 8, 2026` 等内置格式。它不是模糊日期解析器，也不会执行用户正则或代码。

- `15 days ago`、`Oct 2026`、`01/02/2026` 不生成日期。
- 同一字段出现两个不同完整日期时不擅自选择。
- 不合法日期或超过5000字符的日期字段不生成日期。
- 没有时区的日历日期使用既有UTC日历日期规则；不声称取得了源站具体发布时间。
- 此功能不会改变原生RSS/Atom中的日期，也不改变未启用该选项的规则。

日期是必要字段的来源可另设 `min_dated_pct` 质量门槛。数据看板的统计年份应保留在标题或摘要中，不作为发布日期；同一指标的数值修订更新原URL对应条目，保留GUID。
